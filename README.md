# 山田遼祐 / Ryosuke Yamada

AIを活用して、Web・映像・3Dの制作に取り組んでいます。

制作で見つけた課題を、小さく試せる実装に。ここでは、使い道・動かし方・検証内容が分かる部品を公開しています。

## 公開している部品

| 部品 | 解決したいこと |
| --- | --- |
| [Creative Credits Core](https://github.com/YAMADA-Ryosuke-0114/creative-credits-core) | 生成AIの残量を、実測値・推定値・古いデータを区別して表示する |
| [Web Media Controls](https://github.com/YAMADA-Ryosuke-0114/web-media-controls) | 動画の演出を、表示状態と利用者の設定に合わせて制御する |
| [Summary First Stream](https://github.com/YAMADA-Ryosuke-0114/summary-first-stream) | 長い回答の前に、見出しと要約を逐次表示する |

いずれもランタイム依存なしのJavaScriptで、TypeScriptの型定義・テスト・ローカルデモを付けています。AIの支援を使って整理し、出典と公開範囲は各リポジトリに記載しています。残量モニターの参考元である[CodexBar](https://github.com/steipete/CodexBar)は、Peter Steinberger氏らのプロジェクトです。
